# friend-agent

一个「朋友」的运行时 —— 不是自主任务型 agent，也不是编程 agent。
一个人格跑给所有人，每人一份独立记忆；同一个人可跨通道（QQ / Telegram）归并成一条连续会话。

技术栈：TypeScript / Node（Node ≥ 22.6，直接 `node src/index.ts` 跑 `.ts`，无需构建）。

## 跑起来

```bash
cd projects/friend-agent
node src/index.ts          # 跑一遍演示（M0/M1 全链路）
node src/index.ts --cli    # 起本地 CLI 通道，手动聊天
```

## 已验证的关键行为

- 身份合并 → 关库 → 重开：仍是同一人（合并重启不回滚）
- 跨通道验证码：码发已知对话，必须回到发起对话回码；错 6 次作废
- MCP：真实 JSON-RPC 往返（echo/add）、audience 双向过滤、重启自动挂载、退出无孤儿
- 真浏览器：JS 渲染（curl 拿不到的内容）、真实鼠标点击跳转、截图落盘
- **记忆语义召回**（`scripts/memory-vec-test.ts`，真实打硅基流动）：
  - 「他爱吃水果吗」→ 命中「最喜欢吃苹果」（纯关键词命中不了）；「家里有养什么动物」→「橘猫团子」；5 组换说法查询 4 组关键词失败、向量全中
  - rerank 精排生效（「他的宠物叫什么名字」→ 团子 0.992）
  - 坏 key 下 recall 不炸、自动退关键词；关库重开向量从 BLOB 恢复（0ms，无需重算）
- **每日上下文翻篇**（`scripts/daily-context-test.ts`，离线 + mock 模型端到端）：
  - 跨天首条消息自动翻篇：归档落盘 → 摘要进记忆 → 历史（内存 + 库）清空；发给模型的上下文只含今天的内容
  - `/new` 手动提前翻篇：同一天也能立刻归档 + 提炼 + 干净开局；无可归档时友好提示；`/help` 可列出
  - 同日后续轮次正常累积、不再翻篇；「跨天 + 中途重启」也能靠库里最后一条消息的时间正确触发
  - 摘要生成失败有兜底文案（不阻塞翻篇）；归档写盘失败则放弃翻篇、历史一条不丢
  - 过期归档按保留期（60 天）清理，非日期目录不碰
- **面板端到端实测**（`scripts/panel-e2e-test.ts`，Playwright 驱动真 Chromium，80 项全绿）：
  - 16 页遍历渲染 0 JS 异常；Ctrl+K 快速跳转、顶栏刷新、登录墙/退出登录
  - 对话页：对象下拉、发消息、时间戳、输入框自增高、翻篇、导出 txt 下载
  - 全写路径：记忆增删改查（删除带确认）、改称呼、归并、定时任务新建/编辑/立即跑/停用/删除、模型服务商增删改、MCP 真实 stdio 连接 + 工具列表 + 删除
  - 设置页：面板令牌更换（localStorage 即时跟随、锁不死自己）与清除、秘塔 Key、检索偏好；无 key 搜索优雅降级
  - 手机视口（390×844）：抽屉开合、真实命中测试（elementFromPoint）、抽屉层级、Ctrl+K

## 关键设计（写死在代码里的约束）

1. **回注优先级**：本条通道 ▸ `preferredChannel` ▸ 发起通道。
2. **插话**：轮次进行中用户消息进插话槽，在**下一个工具调用间隙**被取走（steering）；没有活动轮次则开新轮。
3. **delegate**：内置工具，立即返回 `{ accepted, taskId }`，不带「大概多久」这类预设话术。
4. **工具超时**：超预算即中止该工具，回复措辞由模型生成，不用模板。
5. **记忆隔离**：记忆按 personId 物理分片；前台只写 hot（短期）记忆，长期记忆交后台提炼。
6. **每日上下文**：上下文按天翻篇——压缩只是同一天内的应急手段，不再承担跨天记忆；跨天记忆 = 前一天摘要进记忆（召回带回）+ 原始对话归档（`archive_query` 可查，保留 60 天）。归档同样按 person 物理分片；`/new` 可手动提前翻篇。
